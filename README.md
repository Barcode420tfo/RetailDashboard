# Retail Dashboard

React/Vite frontend and Express/MongoDB backend with scoped role views, sales analytics, people management and reconciliation.

See [deployment instructions](docs/VERCEL-BACKEND.md) for Vercel plus a hosted backend and MongoDB Atlas. Private business data, spreadsheets, account credentials and local database files are excluded from this public repository.

Install with `npm ci`. Set the backend environment variables and migrate the private database/reference before starting. Build with `npm run build`; Docker starts `server/index.js`.
